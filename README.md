# apolskiy.github.io Personal Portfolio Website
#Aleksandr Polskiy
Repository for my website:
A clean, responsive, and performance-optimized personal portfolio website built with modern web standards and hosted on GitHub Pages.

**Live Website:** [https://apolskiy.github.io](https://apolskiy.github.io)

---

## Features

- **Responsive & Mobile-Optimized:** Designed with a mobile-first approach, ensuring seamless layout transitions, flexible grids, and touch-friendly navigation across smartphones, tablets, and desktop displays.
- **Fast Performance:** Lightweight asset footprint with clean HTML5/CSS3 structures and modular JavaScript for minimal render-blocking behavior.
- **Cross-Browser Compatible:** Tested and verified across modern browser engines (Chromium, WebKit, Gecko).
- **Clean UI/UX:** Clean typography, consistent layout spacing, and intuitive content navigation.

---

## Tech Stack

- **Markup & Styling:** HTML5, CSS3 (Flexbox & CSS Grid, Media Queries)
- **Scripting:** Modern JavaScript (ES6+)
- **IDE & Development:** WebStorm
- **Hosting & Deployment:** GitHub Pages
- **Version Control:** Git
